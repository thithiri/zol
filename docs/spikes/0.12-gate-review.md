# 0.12 Gate review: Phases 0–2

Date: 2026-10-10. Outcome: **gate passed, with the design moved to v0.3.1** (`docs/design-v0.3.1.md`, "Changes from v0.3"). No spike forced a redesign of the vault-head scheme. One fact forces a pool change (Orchard to Ironwood). One finding moves cross-app safety onto an explicit signer rule. One finding changes how the deposit memo travels.

### External facts discovered

- **NU6.3 (Ironwood)** is active on mainnet (3,428,143, 2026-07-28) and testnet (4,134,000). Orchard can no longer receive value or pay other addresses. Vault, deposits, payouts and refunds move to Ironwood v6 transactions. Keys and 43-byte receivers are unchanged. Sources: `zcash_protocol` 0.10.6 `consensus.rs`, `orchard` 0.15.5 `builder.rs` (`CrossAddressDisabled`), ZIP 258, Zebra 6.4.2 `check.rs`.
- **zcashd** reached end of life on 2026-07-18 and does not support NU6.3. Zebra is the only node.
